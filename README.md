# AI Study Companion 🧠

A privacy-focused Chrome extension that helps students and researchers summarize, explain, and quiz themselves on any web content using AI.

## 🚀 Features
- **Summarize**: Get concise overviews of long articles
- **Explain**: Understand complex concepts in simple terms  
- **Quiz Me**: Generate interactive study questions
- **Study Session**: Guided learning with progress tracking
- **100% Client-side**: Works offline, no data leaves your device

## 🛠️ Installation
1. Clone this repository
2. Open `chrome://extensions/`
3. Enable "Developer mode"
4. Click "Load unpacked" and select this folder
5. Select text on any webpage and click the extension icon
